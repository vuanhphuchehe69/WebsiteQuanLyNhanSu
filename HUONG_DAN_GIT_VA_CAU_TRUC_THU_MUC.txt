1. HƯỚNG DẪN ĐẨY MÃ NGUỒN LÊN GITHUB / GITLAB CHI TIẾT TỪ A ĐẾN Z
========================================================================================

Hiện tại, toàn bộ mã nguồn và lịch sử các commit đều đã được lưu trữ an toàn trong kho Git
cục bộ (Local Git) trên máy của bạn. Để đưa mã nguồn lên tài khoản GitHub hoặc GitLab,
bạn thực hiện tuần tự theo các bước dưới đây:

BƯỚC 1: TẠO REPOSITORY TRÊN GITHUB / GITLAB
1. Đăng nhập vào tài khoản GitHub (https://github.com) hoặc GitLab (https://gitlab.com).
2. Bấm vào nút "New" (hoặc dấu "+") để tạo một Repository mới.
3. Đặt tên Repository, ví dụ: "WebsiteQuanLyNhanSu" hoặc "HRM_Nhom9".
4. Chọn chế độ Public hoặc Private tùy nhu cầu.
5. LƯU Ý QUAN TRỌNG: KHÔNG tích chọn "Add a README file", "Add .gitignore" hay "Choose a license"
   (vì dự án trên máy bạn đã có sẵn mã nguồn đầy đủ, nếu tích chọn sẽ gây xung đột lịch sử commit).
6. Bấm "Create repository".
7. Sao chép đường dẫn URL của Repository vừa tạo, có dạng:
   - HTTPS: https://github.com/<tai-khoan-cua-ban>/WebsiteQuanLyNhanSu.git
   - Hoặc SSH: git@github.com:<tai-khoan-cua-ban>/WebsiteQuanLyNhanSu.git

BƯỚC 2: MỞ POWERSHELL / TERMINAL TẠI THƯ MỤC DỰ ÁN
1. Mở PowerShell hoặc Command Prompt.
2. Di chuyển vào thư mục dự án:
   cd d:\Ghost\WebsiteQuanLyNhanSu

BƯỚC 3: KẾT NỐI VÀ ĐẨY MÃ NGUỒN LÊN GITHUB
Chạy lần lượt 3 lệnh sau (thay đường link URL bằng link GitHub bạn vừa copy ở Bước 1):

   git remote add origin https://github.com/<tai-khoan-cua-ban>/WebsiteQuanLyNhanSu.git
   git branch -M master
   git push -u origin master

(Nếu trình duyệt hoặc terminal yêu cầu đăng nhập, bạn chọn "Sign in with browser" hoặc nhập
Personal Access Token (PAT) của GitHub).

BƯỚC 4: QUY TRÌNH ĐẨY THAY ĐỔI TRONG NHỮNG LẦN TIẾP THEO
Mỗi khi bạn sửa code và muốn lưu lại rồi đẩy lên GitHub, chỉ cần chạy 3 lệnh đơn giản:
   git add -A
   git commit -m "noi dung thay doi cua ban"
   git push

BƯỚC 5: XỬ LÝ SỰ CỐ THƯỜNG GẶP
- Trường hợp báo lỗi "remote origin already exists":
  Chạy lệnh: git remote set-url origin <URL_MOI_CUA_BAN>
- Trường hợp báo lỗi "failed to push some refs (fetch first)":
  Chạy lệnh: git pull origin master --rebase
  Sau đó chạy: git push -u origin master
- Xem lại lịch sử commit trên máy:
  Chạy lệnh: git log --oneline -n 10
